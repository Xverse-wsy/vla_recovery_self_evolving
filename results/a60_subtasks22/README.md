## 训练范围与片段边界

专家和完整自主成功分别贡献 6,632、3,232 个窗口，22 段贡献 1,194 个窗口、1,311 个独立动作。13 个中间片段只允许完整真实 H10 窗口，尾部不补齐；9 个有最终任务成功记录的片段沿用成功尾部重复末动作规则。不额外物理删除片段末尾 10 步，prompt 始终使用父轨迹完整任务指令。

全参数 SFT 使用 global batch 128、原生 H10×32 FM 均值、原始归一化统计以及 A60 的优化器和调度设置。训练源版本为 `eac29d4`，操作说明为该版本的 `README_SUBTASKS22.md`。结果分支保存发布材料，不代表其保留的训练代码已更新到该版本。

执行适配保留确定的梯度平均结果及完整权重重载，并扩展评测标签。首次启动因短测入口缺少显式 batch 参数，在模型加载前退出；补充参数后短测和恢复验证通过，正式训练完整完成。该启动错误没有造成缺失训练轮次。
