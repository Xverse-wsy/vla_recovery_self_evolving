# 新版 Stage1：方案 1 完整结果

本目录记录全参数 Stage1 的完整训练与评测结果：50 轮、5,250 次更新，随后完成 2,000 条 LIBERO 评测，成功 1,461 条，总成功率 **73.05%**。

| Suite | 成功数 / 评测数 | 成功率 |
| --- | ---: | ---: |
| Spatial | 432 / 500 | 86.40% |
| Object | 493 / 500 | 98.60% |
| Goal | 419 / 500 | 83.80% |
| LIBERO-10 | 117 / 500 | 23.40% |
| **Overall** | **1,461 / 2,000** | **73.05%** |

`summary.json` 保存统计，`training.json` 保存训练配方，`protocol.json` 保存评测设置，`comparison.json` 保存固定历史参考及比较限制，`manifest.json` 保存发布文件的 SHA-256 和核验范围。逐条输出、训练指标与视频见 [output/stage1_scheme1](../../output/stage1_scheme1/README.md)。

新版 Stage1 以原始 few-shot 模型初始化，使用 13,407 个窗口：专家 6,632、自主成功 3,232、VLA 推进 3,543。严格 CAP 匹配准入为 0，因此本轮没有 CAP 后缀监督。全参数训练使用原生 H10×32 FM 均值、global batch 128，完整遍历 50 次，不使用验证集或早停。

相对旧 Stage1 的 63.40%，新版本提高 9.65 个百分点；相对固定 Baseline 的 74.20% 低 1.15 个百分点，相对固定 A60 的 75.95% 低 2.90 个百分点。本轮未达到超过 A60 的目标。

新版使用 5 步推理，历史参考使用 3 步；历史 A60/B80 的加载方式也有差异。任务、trial、初始状态哈希和归一化统计已核对一致，但不能把成功率差值解释为单一训练因素的贡献。训练与评测初始状态是否重合仍为 unknown。

训练启动时曾因 checkpoint 中的 tuple 与 JSON 中的 list 被直接比较而误报身份不一致。统一 JSON 表示后校验通过，并从第 2 次更新恢复，最终更新序列连续、训练预算完整。该修正仅涉及检查逻辑，不改变训练代码、配置或已有权重。

本轮已完成训练、导出一致性检查和完整评测。旧 Stage2 入口不兼容新版 Stage1，本记录不包含 Stage2 成绩。脱敏范围是本次发布文件及视频归档；原始运行目录单独保留。
