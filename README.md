# π0.5 LIBERO 训练与评测记录

本仓库提供训练与评测适配代码，并保存已完成实验的脱敏结果。本次 A60＋原始 22 个复核子片段已完成 50 轮训练和 2,000 条 LIBERO 评测，成功率为 **71.05%**；结果与比较限制见 [本次结果](results/a60_subtasks22/README.md) 和 [汇总记录](RESULTS_AND_DIAGNOSIS.md)。

## 已完成的结果

每个模型覆盖四个标准 LIBERO suite，每个 suite 10 个任务，每任务 50 个预设初始状态。下表按历史参考和 Stage1 版本列出，推理步数及历史权重加载方式存在差异，不能视为统一协议的受控排名。

新版 Stage1 比旧版高 9.65 个百分点，比固定 A60 参考低 2.90 个百分点。本轮未达到超过 A60 的目标；该差值不能单独归因于数据筛选、参数训练范围或推理步数。Baseline、A60、B80 保留历史成绩，不安排复评。

## 新版 Stage1 配方

从原始 few-shot 模型初始化，全参数训练，使用原生 H10×32 FM 均值与 A60 配方的优化器设置。13,407 个训练窗口包括专家 6,632、自主成功 3,232、VLA 推进片段 3,543；严格 CAP 准入为 0。全部窗口用于训练，global batch 为 128，完整 50 轮共 5,250 次更新、670,350 次窗口呈现。旧 Stage1 权重未用作初始化。

中途 VLA 推进片段已删除末 10 步，训练仅纳入完整真实窗口；专家和完整自主成功轨迹尾部允许重复末动作。配方与实际完成状态分别见 [training.json](results/stage1_scheme1/training.json) 和 [status.json](output/stage1_scheme1/training/status.json)。

本次训练使用提交 [`96c4fe8`](https://github.com/Xverse-wsy/vla_recovery_self_evolving/commit/96c4fe8815ac52a72fcf467dd018606f3eff82d9) 的代码，操作入口为该版本的 `pi05_recovery_pair/README_STAGE1.md`。本结果分支保留既有代码历史，复现新版实验需使用记录的代码版本。Stage2 旧入口与新版全参数 Stage1 不兼容，本轮未运行 Stage2。

## 比较限制

新版评测使用 5 个 flow steps，历史结果使用 3 个；其余任务范围、seed 0、长度为 10 的预测窗口、每次执行 5 个动作和归一化统计保持一致。新版与四个历史模型的任务、trial 和初始状态哈希逐条一致，但训练与评测初始状态重合情况未核实，不能声称独立留出集评测。

历史 A60/B80 完整权重加载涉及中间 dtype 舍入，新旧 Stage1 使用 dtype 配置后重载完整权重的流程。发布资料保留这项差异，不把历史成绩换算成尚未测量的修正结果。
